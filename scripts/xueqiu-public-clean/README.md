# 雪球公开页面净化

面向雪球公开搜索页、股票详情页和帖子详情页的油猴脚本，用于减少登录弹窗与下载推广造成的干扰，并对长列表加载和非必要追踪做低风险优化。

## 安装

[点击安装雪球公开页面净化](https://raw.githubusercontent.com/techidsk/userscripts/main/scripts/xueqiu-public-clean/xueqiu-public-clean.user.js)

需要先安装 Tampermonkey 或兼容的用户脚本管理器。

## 功能

- 自动关闭搜索页和股票详情页在浏览公开内容时出现的登录弹窗，并清理遮罩与页面滚动锁。
- 未登录时点击股票动态中的评论数字或“讨论”，转到对应帖子的公开讨论区，避免触发仅用于登录的行内入口。
- 完整保留页面顶部的手动登录流程及登录二维码。
- 移除顶部和侧边的 App 下载推广组件。
- 为非登录图片启用原生延迟加载和异步解码，并延迟渲染视口外的时间线条目。
- 阻止百度统计脚本，并利用雪球现有的初始化标记停用站内网页行为事件上报。
- 缩小 DOM 属性监听范围，对页面动态内容进行合并处理。

## 配置

脚本没有快捷键或油猴菜单命令。可以编辑脚本顶部的 `OPTIONS`，单独关闭评论跳转、推广清理、图片优化、长列表优化或隐私保护功能。

## 隐私与运行方式

脚本不收集、保存或上传用户数据。

脚本需要在 `document-start` 运行，并通过 `@sandbox raw` 进入页面主世界，原因是百度统计脚本和雪球内部行为监听都可能在页面初始化早期加载。对 DOM 方法的临时保护只匹配 `hm.baidu.com/hm.js`，并在 `DOMContentLoaded` 后恢复原方法。

脚本不会拦截数美、阿里等反滥用或安全校验脚本，也不会处理登录二维码资源，以免破坏页面访问和用户主动登录。它不是浏览器网络层防火墙，无法保证阻止用户脚本执行前已经发出的请求。

## 兼容性与限制

- 主要面向桌面版 Chromium 浏览器和 Tampermonkey。
- 评论跳转仅处理雪球股票详情页时间线中能找到公开帖子地址的条目。
- 脚本只改善公开内容的浏览体验；服务器明确要求登录的内容仍然无法访问。
- 雪球调整页面结构、类名或初始化逻辑后，相关功能可能需要同步更新。
