# 斗鱼极简直播间

面向斗鱼网页直播间的精简油猴脚本，保留直播画面、普通弹幕和播放器控制，将页面变成更干净的观看界面。

## 安装

[点击安装斗鱼极简直播间](https://raw.githubusercontent.com/techidsk/userscripts/main/scripts/douyu-clean/douyu-clean.user.js)

需要先安装 Tampermonkey 或兼容的用户脚本管理器。

## 功能

- 进入直播间后默认使用网页全屏布局，播放器铺满当前标签页。
- 在画质菜单可用时自动选择最高且未锁定的画质。
- 隐藏顶部活动、主播信息侧栏、礼物栏、贵族/VIP、超级弹幕和活动组件。
- 隐藏并暂停常见礼物、入场、SVGA、VAP 和视频特效。
- 清理页面皮肤、装饰背景和背景图片。
- 拦截已识别的斗鱼统计、广告上报、APM 以及常见第三方分析 SDK。
- 保留直播流、登录、普通弹幕连接和播放器控制。

## 快捷键与菜单

- `Alt+Shift+D`：切换极简模式。
- `Shift+F`：进入或退出浏览器原生全屏。
- 油猴菜单可重新选择最高可用画质，并查看本页追踪拦截统计。

## 画质选择规则

脚本会等待播放器画质菜单出现，然后选择列表中最高且可用的一项。如果原画需要登录、会员或尚未解锁，会选择下一档。每个播放器只自动设置一次，之后尊重手动选择。

## 隐私拦截说明

脚本在 `document-start` 阶段拦截匹配的 `fetch`、XHR、`sendBeacon`、统计脚本和追踪像素，并为部分统计 SDK 提供空实现，以减少错误重试。它不是浏览器网络层防火墙，无法保证拦截扩展注入前已经发出的极早请求。

## 兼容性

主要面向桌面版 Chromium 浏览器和 Tampermonkey。斗鱼更新页面结构后，个别选择器或画质逻辑可能需要同步调整。

遇到播放、画质或布局问题时，请提交 [Issue](https://github.com/techidsk/userscripts/issues)，并附上直播间地址、浏览器版本和问题截图。
