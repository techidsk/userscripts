# Changelog

本文件记录“斗鱼极简直播间”的用户可感知变化。

## [1.2.0] - 2026-08-09

- 拦截已识别的斗鱼统计、广告上报、APM 和常见第三方分析 SDK。
- 增加追踪拦截统计菜单和统计 SDK 空实现，减少失败重试。
- 缩小 DOM 观察范围，降低直播间持续更新时的脚本开销。
- 保留直播流、登录、普通弹幕连接和播放器控制接口。

## [1.1.0] - 2026-08-09

- 自动选择画质列表中最高且可用的一项。
- 跳过需要登录、VIP、会员或尚未解锁的画质。
- 每个播放器只自动设置一次，之后尊重手动选择。

## [1.0.0] - 2026-08-09

- 默认启用网页全屏布局。
- 隐藏顶部活动、侧栏、贵族/VIP、超级弹幕、礼物和入场特效。
- 清理直播间皮肤、装饰背景和背景图片。
- 增加极简模式和浏览器原生全屏快捷键。
