# Bilibili 视频下载助手

面向 Bilibili 普通视频页的油猴脚本，用于下载当前视频或指定分 P。脚本既提供包含画面和声音的兼容版，也可以分别下载更高清的 DASH 视频轨与音频轨。

## 安装

[点击安装 Bilibili 视频下载助手](https://raw.githubusercontent.com/techidsk/userscripts/main/scripts/bilibili-video-downloader/bilibili-video-downloader.user.js)

需要先安装 Tampermonkey 或兼容的用户脚本管理器。

## 功能

- 将“下载”入口放在点赞、投币、收藏、分享操作栏中，位于分享右侧。
- 操作栏尚未加载或页面结构不兼容时，自动降级为右侧悬浮按钮。
- 支持多分 P 视频，可在下载面板中选择分 P。
- 下载包含画面和声音的兼容版；接口返回多个分段时会分别保存。
- 列出当前账号可用的 DASH 视频与音频轨，可选择清晰度、编码和音频码率。
- 同时下载视频轨与音频轨，并生成对应的 FFmpeg 无损封装命令。
- 点击下载后立即显示每个文件的状态；支持不确定进度动画、已下载大小、百分比、完成和失败提示。
- 下载失败时自动尝试 Bilibili 返回的备用 CDN 地址。
- 自动清理文件名中不适合本地文件系统的字符。
- 提供适合窄屏使用的下载面板。

## 使用

1. 打开 `https://www.bilibili.com/video/...` 或 `https://m.bilibili.com/video/...` 普通视频页。
2. 点击分享右侧的“下载”；若操作栏尚未出现，则点击页面右侧的悬浮按钮。
3. 需要一个可直接播放的文件时，选择“下载兼容版”。
4. 需要更高清画质时，选择视频轨和音频轨后点击“下载视频 + 音频”。
5. 将面板生成的 FFmpeg 命令复制到两个文件所在的下载目录运行，即可在不重新编码的情况下封装成一个文件。

兼容版通常画质较低，但已经包含声音。DASH 版本通常画质更高，不过 Bilibili 会分别提供视频与音频，因此需要 FFmpeg 完成最终封装。

Tampermonkey 的部分下载模式会等文件接收完成后才把它显示在浏览器下载栏中。点击下载后请以面板内的任务状态为准；这不会影响实际下载。

## 权限与隐私

- `GM_download`：将选中的媒体文件保存到浏览器下载目录，并为 Bilibili CDN 请求附带当前视频页来源信息。
- `GM_setClipboard`：仅在用户点击按钮时复制面板生成的 FFmpeg 命令。
- `GM_xmlhttpRequest`：页面自身的 `fetch` 无法读取 Bilibili 播放接口时，用作同站接口请求的兼容兜底。
- `@connect` 仅包含 Bilibili 播放接口及目前常见的媒体 CDN 域名。

脚本不收集、保存或上传 Cookie、Token、账号信息、下载记录或浏览历史。播放接口请求仍由当前 Bilibili 登录状态决定，脚本不会导出登录凭据。

## 兼容性与限制

- 当前支持普通 `/video/` 页面，不支持番剧、影视、直播和互动视频专用页面。
- 不绕过登录、会员、付费、地区或 DRM 限制，只展示当前账号原本可播放的资源。
- 播放地址是 Bilibili 生成的临时地址，过期后需要在面板中刷新资源。
- DASH 视频轨本身没有声音，必须同时下载音频轨并进行封装。
- 主要面向桌面版 Chromium 浏览器与 Tampermonkey；移动端用户脚本管理器的下载能力可能不同。
- Bilibili 更新页面结构或播放接口后，操作栏位置或资源解析逻辑可能需要同步调整。
