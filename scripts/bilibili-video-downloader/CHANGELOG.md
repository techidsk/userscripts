# Changelog

本文件记录“Bilibili 视频下载助手”的用户可感知变化。

## [1.0.1] - 2026-08-28

- 将下载入口移动到视频操作栏的分享右侧，并匹配操作栏布局。
- 页面操作栏尚未加载或结构变化时，保留右侧悬浮入口作为降级方案。
- 打开下载面板时将面板挂载到页面根节点，避免被操作栏布局裁切。

## [1.0.0] - 2026-08-28

- 支持普通视频页和多分 P 选择。
- 支持下载包含声音的兼容版。
- 支持选择并下载 DASH 视频轨和音频轨。
- 生成与所选文件名对应的 FFmpeg 无损封装命令。
- 增加备用 CDN、文件名清理、下载错误提示和窄屏面板适配。
