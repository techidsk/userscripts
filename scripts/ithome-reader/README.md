# IT之家移动端阅读增强

面向 IT之家移动版新闻列表与热榜的阅读增强油猴脚本。它在保留标题、时间、评论数和缩略图的基础上补充两行新闻导语，并将单图新闻整理为稳定的左右布局。

## 安装

[点击安装 IT之家移动端阅读增强](https://raw.githubusercontent.com/techidsk/userscripts/main/scripts/ithome-reader/ithome-reader.user.js)

需要先安装 Tampermonkey 或兼容的用户脚本管理器。

## 功能

- 为首页、栏目新闻流以及 `/rankm/` 的日榜、周榜、热评和月榜补充两行导语。
- 单图卡片保持严格左右布局：左侧依次显示标题、导语和时间/评论，右侧只显示缩略图。
- 保留热榜的彩色排名编号；关闭图片时也不会隐藏排名。
- 自动处理无限滚动或动态追加的新闻条目。
- 适配 IT之家明亮、黑暗和跟随系统主题。
- 提供导语、图片、紧凑、净化四个页面内开关，并记住选择。
- 净化模式默认隐藏标记为广告的新闻条目和“打开 App”横幅。

## 默认配置

| 开关 | 默认值 | 说明 |
| --- | --- | --- |
| 导语 | 开启 | 为新闻卡片显示最多两行摘要 |
| 图片 | 开启 | 显示单图与三图缩略图 |
| 紧凑 | 关闭 | 开启后缩小卡片间距，并将导语收为一行 |
| 净化 | 开启 | 隐藏广告条目和“打开 App”横幅 |

脚本没有快捷键或油猴菜单命令，所有设置都位于新闻列表顶部的“阅读增强”工具栏。

## 数据、网络与运行方式

脚本不收集或上传用户数据。设置和导语缓存只保存在 `m.ithome.com` 的本地存储中；导语缓存保留 7 天，最多保存 250 条。

首页和栏目页优先从 IT之家自身的同源新闻列表接口批量读取导语。脚本会在 `document-start` 阶段旁路观察 `/api/news/newslistpageget` 和 `/api/news/newstaglistpageget` 的 XHR 响应，以复用无限滚动已经取得的数据；它不会修改请求、响应或页面回调。列表数据缺少导语时，仅为接近视口的新闻读取其同源详情页，最多同时请求 3 篇，并设置 9 秒超时。

## 兼容性与限制

- 主要面向移动版 Chromium 浏览器和 Tampermonkey。
- 支持 `m.ithome.com` 下具有标准新闻卡片结构的列表页和热榜；新闻详情页本身不会被改写。
- 导语来自 IT之家列表接口或详情页描述；来源缺失或请求失败时，卡片会退回原始标题、图片与元信息布局。
- IT之家调整列表容器、卡片类名或接口字段后，相关功能可能需要同步更新。
